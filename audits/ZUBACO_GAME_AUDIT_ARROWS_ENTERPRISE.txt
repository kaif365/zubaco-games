PHASE 1 — GAME FLOW (traced end-to-end)
================================================================================
Endpoints (game.controller.ts) → GameSessionRestateService → Restate virtual
object (game-session.restate.ts) → GameService (game.service.ts). All handlers
gated by SessionGuard + @RequireSession(LOGIN/USER) + @EnableEncryption.

Game Load        → POST v1/game/game-start. Re-entry returns in-flight state;
                   finalized session returned from DB; open-but-no-state →
                   GAME_SESSION_RECOVERY_REQUIRED (409). [OK]
Asset Loading    → Frontend (Phaser GameScene.ts) loads sprites; board+arrows
                   come from server response. No score asset trust. [OK]
Initialization   → createGameSession snapshots stageConfig (timeLimit, levels,
                   maxScore) to DB; totalRounds = Σ boardCount. [OK]
Configuration    → fetchStageConfig requires isEnabled + ≥1 level else 404/422. [OK]
Timer Start      → expiryAt = now + timeLimit*1000; scheduleExpiry arms durable
                   Restate timers (markResultProcessing, finalizeExpired). [OK]
Gameplay         → next-board / submit-moves serialized per (userId:stageId)
                   virtual-object key — no per-session races. [OK]
Move Validation  → server replays moves vs in-state arrows (move-validator). [OK]
Scoring          → server-only (score.util). FE never asserts score. [OK]
Completion       → endBoard advances/finalizes; endGame finalizes. [OK]
Result Submission→ finalizeAndCommit writes boards→arrows→moves→status (status
                   last), idempotent on terminal status. [OK]
Cleanup          → ctx.clearAll() clears virtual-object state post-finalize. [OK]
Transition gap   → next-board UNLOCK GATE is effectively a no-op (see B-01).

PHASE 2 — GAME RULES
================================================================================
[B-01][BLOCKER] Next-board gate always open. constants.ts:
   NEXT_BOARD_ARROWS_REMAINING_THRESHOLD=1, NEXT_BOARD_SOLVE_PCT_THRESHOLD=0.
   unlock = remaining<=1 || (total>0 && removed/total>=0). removed/total>=0 is
   ALWAYS true → next-board callable with ZERO arrows removed; player skips
   every board harvesting partial scores w/o solving. (Prior BLOCKER-4) PRESENT.
[OK] Arrow generation: boards/arrows authored in DB; server picks, FE renders.
[OK] Win: all arrows removed all rounds within timeLimit → ENDED + bonus.
[OK] Lose/Timeout: expiry → RESULT_PROCESSING → finalizeExpired → EXPIRED, 0 bonus.
[OK] Restart: new game-start blocked while STARTED/RESULT_PROCESSING (409).
[MED] No explicit pause/resume; wall-clock expiryAt only. Mobile backgrounding
   burns time (fair, but poor UX).
