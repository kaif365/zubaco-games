PHASE 2 — GAME RULES
================================================================================
[OK] move rules server-validated: source non-empty, dest under capacity, top-colour
   match or empty dest, no same-tube; win = all tubes empty or full-uniform.
[B-01][BLOCKER] generatePuzzle only seededShuffle()s balls into tubes — NO solver
   verification. Unlike block-fill/arrows, NOTHING guarantees the puzzle is
   solvable; an unsolvable shuffle is payable in a real-money tournament. Fairness
   defect. (gov GAME-002)
[B-02][HIGH] level mismatch: start scales config via getLevelConfig(level) but
   session stores no level; submit replays with BASE Configuration → solved/score
   diverge → false cheat flag + score loss in ranked/level play.
[MED] no pause/resume; wall-clock only. tube capacity ok.
