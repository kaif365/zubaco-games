PHASE 2 — GAME RULES
================================================================================
[OK] schedule server-regenerated (mulberry32) — grid/changes/activate/revert
   deterministic; level scaling persisted in snapshot (no replay mismatch).
[B-01][BLOCKER] validateTap is membership-only: a tap is "correct" if any active
   change matches the cell+window — taps are NOT deduped per change, so spamming
   the same active cell counts every tap as correct → correctTaps unbounded
   (≫ changeCount), score inflation up to the 500-tap cap. (gov GAME-002)
[MED] no pause/resume. tolerance 500ms each side + displayDuration = wide window.
