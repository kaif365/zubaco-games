3. DETAILED TECHNICAL AUDIT CRITERIA & INVARIANTS
------------------------------------------------------------------------------------------------------------------------
- 7.1 Cryptographic Game Sessions:
  * Provably fair session creation with HMAC-SHA256 server seed commitment, client seed pair, and monotonic nonce.
  * Tamper-proof session completion verification: client cannot forge scores without matching server verification token.
  * Replay attack prevention: single-use session tokens locked in Redis with 1-hour expiration.

- 7.2 Biomechanics & Cadence Heuristics:
  * Minimum human neuromuscular reaction threshold: reject or flag click cadences < 50ms.
  * Robotic regularity check: standard deviation of event intervals $\sigma < 5\text{ms}$ over $\ge 10$ events triggers BOT flag.
  * Spatial trajectory jitter: synthetic zero-jitter click coordinates (exact identical pixel coordinates across multiple clicks).

- 7.3 Memory Tampering & Speedhack Defense:
  * Timestamp monotonic verification: client event timestamp delta must strictly correlate with server wall-clock duration ($\pm 3000\text{ms}$ network jitter tolerance).
  * Mathematical maximum score validation per game: rejecting scores exceeding theoretical maximum possible given game duration and rule constraints.
  * Impossible completion timing: rejecting completion before minimum physical level traversal time.

- 7.4 Device Fingerprinting & Multi-Accounting Radar:
  * SHA-256 hardware fingerprint extraction (IMEI / Android ID / iOS IDFV / Screen / Hardware specs).
  * Anti-Sybil tournament cohort constraint: identical device fingerprints prohibited from sharing the same tournament cohort.
  * Rapid IP velocity clustering detection: flagging > 3 accounts actively playing simultaneously from identical residential / VPN IPs.

- 7.5 Authoritative Enforcement & Penetration Test Suite:
  * Atomic transactional execution: `DISQUALIFY_SESSION`, `REMOVE_LEADERBOARD_SCORE`, `FREEZE_WALLET`, `BAN_USER`.
  * Proactive Redis ban cache update (`auth:ban:${userId} = 1`) for zero-delay JWT request termination.
  * Automated penetration test suite simulating real-world bot injection, forged payloads, and replay exploits.
