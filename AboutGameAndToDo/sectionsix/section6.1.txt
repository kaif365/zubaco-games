2. TECHNICAL ARCHITECTURE & MATHEMATICAL INVARIANTS
------------------------------------------------------------------------------------------------------------------------
A. CCU Computation:
   - Evaluated via live Redis active session keys `ws:session:*` across multi-node cluster.

B. Velocity Spike Detection Formula:
   - Given 24-hour baseline hourly average: `AvgHourlyVolume = TotalVolume24h / 24`.
   - Current hour volume: `VolumeCurrentHour`.
   - Velocity Spike flagged if: `VolumeCurrentHour > Math.max(10000, AvgHourlyVolume * 3)`.

C. Health Latency Guarantees:
   - Database ping latency measured via `SELECT 1` execution.
   - Redis ping latency measured via `Redis.ping()` round-trip.
   - Process heap and RSS memory tracked in megabytes.
