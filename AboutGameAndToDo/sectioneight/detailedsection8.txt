3. DETAILED TECHNICAL BENCHMARKING TARGETS & PERFORMANCE INVARIANTS
------------------------------------------------------------------------------------------------------------------------
- 8.1 Transactional Concurrency (Registration Rush):
  * Simulate 2,000 concurrent tournament entry requests in the final 60-second window.
  * Verify double-entry ledger balance check and atomic wallet debit without deadlocks or race conditions.
  * P99 latency target < 150ms for entry fee deductions. Zero negative balance occurrences.

- 8.2 WebSocket Fan-Out & Countdown Broadcast:
  * Simulate 1,000 concurrent WebSockets receiving `STAGE_START` countdown broadcast at the exact same millisecond.
  * Zero dropped sockets, round-trip message delivery latency < 50ms across India.
  * Backpressure handling and non-blocking socket buffer drain.

- 8.3 Cutoff Stampede & Redis Leaderboards:
  * 1,000 game-over score submissions landing within a 10-second window.
  * Real-time Redis `ZADD` sorted set updates with atomic rank computation (`ZREVRANK`).
  * Tie-breaking resolution via monotonic timestamp floating-point score weighting.

- 8.4 Database Connection Pooling & Index Optimization:
  * Transaction-mode connection pooling (PgBouncer max 200 server connections).
  * Verification of composite indexes for `user_wallets`, `game_sessions`, `stage_entries`, and `cheat_flags`.
  * Elimination of sequential table scans on hot transaction pathways.

- 8.5 Redis Memory & Cache Eviction Governance:
  * Strict memory bounding with `volatile-lru` eviction policy.
  * Enforced TTL on all transient keys (match tickets, anti-replay guards, fast-path ban flags).
