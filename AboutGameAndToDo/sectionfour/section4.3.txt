2. TECHNICAL ARCHITECTURE & MATHEMATICAL INVARIANTS CERTIFIED
------------------------------------------------------------------------------------------------------------------------
A. Cryptographic HMAC SHA-256 Invariants:
   - Razorpay: `expected = HMAC-SHA256(webhookSecret, rawBody).hex`. Verified with timingSafeEqual.
   - Cashfree: `expected = HMAC-SHA256(cashfreeSecret, timestamp + rawBody).base64/hex`.
   - Length pre-checks guard against Node.js `timingSafeEqual` `RangeError`, returning deterministic HTTP 400.

B. Idempotency Engine (`payment_webhook_events`):
   - Every inbound webhook extracts or computes a deterministic event ID (`provider:eventId`).
   - Fast Redis check + atomic `setnx` lock prevents concurrent duplicate processing.
   - Upon initial receipt, event is registered with a 30-day retention window.
   - Subsequent duplicate webhook deliveries from provider retries return `{ received: true, duplicate: true }`
     immediately without issuing duplicate ledger credits or triggering race conditions.
