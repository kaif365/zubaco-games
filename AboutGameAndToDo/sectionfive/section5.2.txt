2. TECHNICAL ARCHITECTURE & MATHEMATICAL INVARIANTS
------------------------------------------------------------------------------------------------------------------------
A. State Machine Transition Graph:
   `DRAFT` -> `REGISTRATION_OPEN` -> `REGISTRATION_CLOSED`
   -> `STAGE_1_LIVE` -> `STAGE_1_TALLY`
   -> `STAGE_2_LIVE` -> `STAGE_2_TALLY`
   -> `STAGE_3_LIVE` -> `STAGE_3_TALLY`
   -> `STAGE_4_LIVE` -> `STAGE_4_TALLY`
   -> `STAGE_5_LIVE` -> `STAGE_5_TALLY`
   -> `PRIZE_CALCULATION` -> `PRIZE_DISTRIBUTED` -> `ARCHIVED`.

B. Stage Tally Cut-off:
   - Rank all active cohort/tournament participants by compound score descending.
   - Elimination threshold: bottom `EliminationPct%` flagged as `is_eliminated = true`.
   - Remaining top `(100 - EliminationPct)%` advance to next stage bracket.
