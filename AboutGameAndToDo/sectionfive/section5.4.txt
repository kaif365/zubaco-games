2. TECHNICAL ARCHITECTURE & MATHEMATICAL INVARIANTS
------------------------------------------------------------------------------------------------------------------------
A. Compound Score Formula:
   - Base game score: `S` (integer).
   - Time elapsed in milliseconds: `T_ms` (0 to 180,000ms for 3-minute max matches).
   - Maximum allowed time: `T_max = 180,000ms`.
   - Remaining time: `T_rem = Math.max(0, T_max - T_ms)`.
   - Microsecond decimal component: `D = T_rem / 1,000,000`.
   - `CompoundScore = S + D`.
   - Mathematical Invariant Verified:
     * `S1 > S2 => CompoundScore1 > CompoundScore2` (Higher base score always beats lower base score).
     * If `S1 == S2`, faster finish => higher `T_rem` => higher decimal component, definitively breaking ties.

B. Redis Sorted Set Storage:
   - Cohort Key: `lb:tourn:${tournamentId}:stage:${stageNumber}:cohort:${cohortId}`
   - Unified Key: `lb:tourn:${tournamentId}:stage:${stageNumber}:unified`
   - Member: `userId`, Score: `CompoundScore`.
   - O(log N) retrieval via `ZREVRANK` and `ZREVRANGE`.
