3. DETAILED TECHNICAL ARCHITECTURE & DEVOPS INVARIANTS
------------------------------------------------------------------------------------------------------------------------
- 9.1 Docker & Cloud Topology:
  * Multi-stage minimal production Dockerfiles (`node:20-alpine`) with non-root security user (`USER node`).
  * CloudFront CDN caching policy with Brotli/Gzip compression and immutable cache-control for static assets.
  * Application Load Balancer path routing (`/api` -> Platform, `/tournament` -> WS, `/admin` -> Admin).

- 9.2 CI/CD GitHub Actions:
  * Matrix testing across Node.js versions with dependency caching.
  * Parallel job execution: linting, unit tests, E2E penetration suite, production build certification.
  * Automated staging deployments on push to `main` with branch protection.

- 9.3 Sentry APM:
  * Sentry initialization across `zubaco-platform` and `zubaco-admin-panel`.
  * Sensitive data scrubbing (PII, passwords, OTPs, auth tokens, bank credentials).
  * Unhandled promise rejection and exception capture.

- 9.4 Prometheus & Grafana Metrics:
  * Prometheus exposition format at `/metrics`.
  * Metrics: `active_websocket_connections`, `tournament_stage_transitions`, `http_request_duration_seconds`,
    `wallet_transactions_total`, `anti_cheat_flags_total`.

- 9.5 Health & Probes:
  * HTTP GET `/health/liveness` (returns 200 OK if Node process is responsive).
  * HTTP GET `/health/readiness` (verifies PostgreSQL connection and Redis ping before receiving traffic).
  * Automated threshold alerting: error rate > 1%, connection pool > 85%, webhook failures > 2%.
