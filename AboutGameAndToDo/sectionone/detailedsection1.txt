5. COMMON BUILD ERROR TYPES & RESOLUTION PROTOCOLS
------------------------------------------------------------------------------------------------------------------------
Error Category          | Likely Root Cause                                      | Standard Resolution Protocol
------------------------+--------------------------------------------------------+--------------------------------------
TypeScript Type Errors  | Missing or mismatched interface fields in DTOs         | Update type definition in shared types
Missing Dependencies    | Package imported in code but absent from package.json  | Add dependency to `package.json`
Path Resolution Failure | Case-sensitive or relative import mismatch             | Fix exact path import with forward slash
Vite Asset Resolution   | Static assets referenced outside `public/` or `src/`   | Relocate or update import URL
Prisma Client Missing   | `prisma generate` not run before `nest build`          | Add prebuild step `prisma generate`
Next.js SSR/Hydration   | Browser-only APIs (`window`, `localStorage`) in SSR   | Wrap in `typeof window !== 'undefined'`
React Native Metro      | Missing native module links or polyfills               | Verify mock configurations in jest/metro
