[ ] TC-01: TOURNAMENT REGISTRATION RUSH BENCHMARK (2,000 CCU)
    - Action: Run `k6 run zubaco-games/load-tests/tournament-registration-rush.k6.js`.
    - Workload: 2,000 virtual users hitting `/wallet/debit-entry-fee` simultaneously.
    - Expected Result:

      * Zero database deadlocks (`ERROR 40P01`).
      * 99th percentile HTTP latency < 250ms.
      * Final database check proves zero balance variance.

[ ] TC-02: WEBSOCKET FAN-OUT & COUNTDOWN BROADCAST (1,000 CONCURRENT CLIENTS)
    - Action: Run `k6 run zubaco-games/load-tests/websocket-broadcast-rush.k6.js`.
    - Workload: 1,000 persistent WebSocket connections subscribed to active tournament room.
    - Expected Result:
      * All 1,000 sockets connect within 5 seconds.
      * Instantaneous broadcast of `STAGE_START` delivers to 1,000 clients in < 50ms.
      * Node.js event loop lag stays under 20ms.

[ ] TC-03: STAGE CUTOFF STAMPEDE (1,000 SCORE SUBMISSIONS IN 10 SECONDS)
    - Action: Run `k6 run zubaco-games/load-tests/stage-cutoff-stampede.k6.js`.
    - Workload: 1,000 players submitting final game scores in the final 10 seconds before cutoff.
    - Expected Result:
      * Redis Sorted Sets (`ZADD`) ingests scores at > 3,000 ops/sec without connection dropping.
      * Real-time leaderboard updates with microsecond tie-breaking.
      * Scores submitted after 00:00.000 are rejected cleanly with `STAGE_ALREADY_CLOSED`.
