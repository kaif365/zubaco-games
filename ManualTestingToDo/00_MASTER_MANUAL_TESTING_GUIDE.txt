   - Mid-game phone call and backgrounding interruption handling.

4. `sectionfour_central_platform_backend/`:
   - User SMS OTP authentication lifecycle and JWT refresh tokens.
   - Wallet deposit rush, UPI gateway mock callbacks, instant withdrawals.

5. `sectionfive_tournaments_and_websockets/`:
   - 5-Stage tournament state machine transitions (Registration -> Round of 16 -> Quarters -> Semis -> Finals).
   - Real-time WebSocket connection, reconnection jitter, and broadcast fan-out.

3. GLOBAL PASS/FAIL STANDARD & CRITICAL SEVERITY CLASSIFICATION
========================================================================================================================
When testing, every issue found must be tagged with a severity level:
- [BLOCKER / P0] : Financial double-spend, wallet balance leakage, crash on launch, game unsolvable, match ticket exploit.
- [CRITICAL / P1]: Score submission failure, WebSocket disconnection without auto-reconnect, KYC upload failure, 5xx API errors.
- [MAJOR / P2]   : Visual glitch on specific screen ratios, audio desync on iOS, level difficulty jump too steep.
- [MINOR / P3]   : Cosmetic typo, padding alignment off by a few pixels, animation stutter under 30 FPS.

A module is ONLY signed off as PASS when there are ZERO P0 and ZERO P1 bugs remaining.
