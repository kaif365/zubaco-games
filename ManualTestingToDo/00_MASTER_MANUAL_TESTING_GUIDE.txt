HOW TO BOOTSTRAP THE ENTIRE PLATFORM LOCALLY (FROM SCRATCH):
------------------------------------------------------------------------------------------------------------------------
1. Boot Infrastructure:
   $ cd c:\Users\Ashar\Desktop\zubaco-games
   $ docker-compose up -d postgres redis

2. Start Central Platform Core (Port 3000):
   $ cd zubaco-platform
   $ npm install
   $ npx prisma migrate deploy
   $ npm run start:dev

3. Start Admin Panel (Backend: Port 3001 | Frontend: Port 3002):
   $ cd ../zubaco-admin-panel-repo/zubaco-admin-panel/backend && npm run start:dev
   $ cd ../frontend && npm run dev

4. Start Web Lobby (Port 5173):
   $ cd ../../../zubaco-web-lobby && npm run dev

5. Start Mobile App Shell (Android Emulator / iOS Simulator):
   $ cd ../zubaco-mobile && npm start

6. Start Any Game Backend & Frontend (e.g. Sequence Recall):
   $ cd ../zubaco-games/sequence-recall/sequence-recall-backend && npm run start:dev
   $ cd ../sequence-recall-frontend && npm run dev
