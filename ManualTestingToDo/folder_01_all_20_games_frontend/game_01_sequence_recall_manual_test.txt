SECTION 1: HOW TO BOOT AND RUN THIS GAME LOCALLY (STEP-BY-STEP)
------------------------------------------------------------------------------------------------------------------------
Step 1: Open a terminal in the root directory:
   $ cd c:\Users\Ashar\Desktop\zubaco-games\zubaco-games\sequence-recall\sequence-recall-frontend

Step 2: Ensure all node modules are installed:
   $ npm install

Step 3: Launch the local development server:
   $ npm run start:development
   (or run: npx vite --port 3005 if port 3000 is occupied)

Step 4: Open your web browser (Desktop Chrome or Mobile Device Emulator):
   URL: http://localhost:3000 (or http://localhost:3005)
   Tip: Press F12 -> Toggle Device Toolbar (Ctrl + Shift + M) -> Select "iPhone 14 Pro" or "Pixel 7" (390 x 844 px).
