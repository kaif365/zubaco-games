2. MANUAL TEST SUITE & STEP-BY-STEP CHECKLIST:
------------------------------------------------------------------------------------------------------------------------

[ ] TC-01: OBSERVATION STAGE & OBJECT RENDERING
    - Action: Start match. Observe scene with various distinct objects placed inside room or grid compartments.
    - Expected Result:
      * Objects are clearly distinct (e.g. Lamp, Book, Clock, Keys) with sharp vector/png graphics.
      * Countdown bar displays remaining memorization time (e.g. 5 seconds).
      * Object positions are unambiguously aligned with grid cells.

[ ] TC-02: OBJECT WIPEOUT & TRAY APPEARANCE
    - Action: Wait for memorization timer to reach 0.
    - Expected Result:
      * Grid clears instantly to empty slots.
      * An object drawer / inventory tray appears at the bottom containing all memorized objects.
      * Player timer begins countdown for reconstruction phase.

[ ] TC-03: DRAG AND DROP / TAP-TO-PLACE BEHAVIOR
    - Action: Drag an object from tray and drop it into a grid slot (or tap object, then tap slot).
    - Expected Result:
      * Object follows finger/mouse smoothly during drag.
      * Object snaps cleanly into the targeted grid cell.
      * Object is removed from or greyed out in the bottom inventory tray.

[ ] TC-04: OBJECT REPOSITIONING & SWAPPING
    - Action: Move an already placed object from Slot A to Slot B, or drag it back to tray.
    - Expected Result:
      * Player can freely adjust placements before hitting "Submit".
      * If Slot B already has an item, items swap places smoothly.

[ ] TC-05: ACCURACY EVALUATION & SCORING
    - Action: Place 3 objects in correct locations and 1 in an incorrect slot, then press "Submit".
    - Expected Result:
      * Correct slots glow green; incorrect slot glows red.
      * Score is computed proportionally (e.g., 75% accuracy + time bonus).
      * True position of the mistaken object is shown in ghost outline.

[ ] TC-06: DROP OUTSIDE TARGET BOUNDARIES
    - Action: Drag an object and release it outside the playable grid into header or footer.
    - Expected Result:
      * Object bounces back smoothly to the inventory tray.
      * Does not disappear or get stuck off-screen.

[ ] TC-07: LEVEL SCALING (LEVELS 1 TO 10)
    - Action: Advance through higher levels.
    - Expected Result:
      * Object count increases from 3 objects (Level 1) up to 8 objects (Level 10).
      * Grid complexity expands (e.g., 3x3 to 4x4 or complex room furniture).
