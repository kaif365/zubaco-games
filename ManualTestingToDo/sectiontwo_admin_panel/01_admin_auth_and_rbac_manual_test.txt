------------------------------------------------------------------------------------------------------------------------
2. MANUAL TEST SUITE & STEP-BY-STEP CHECKLIST:
------------------------------------------------------------------------------------------------------------------------

[ ] TC-01: ADMIN LOGIN WITH VALID CREDENTIALS
    - Action: Open `http://localhost:3002`. Enter valid credentials (`admin@zubaco.com` / `Admin@Zubaco2026!`).
    - Expected Result:
      * Authentication succeeds, JWT token is securely stored in HttpOnly cookie or secure storage.
      * User is redirected to `/dashboard`.
      * Admin name and role badge ("SUPER_ADMIN") appear in header.

[ ] TC-02: INVALID CREDENTIALS & BRUTE-FORCE LOCKOUT
    - Action: Enter wrong password 5 times consecutively.
    - Expected Result:
      * Error message displays: "Invalid email or password".
      * On 5th attempt, rate limiter / lockout triggers with HTTP 429 "Too Many Requests, retry in 60s".

[ ] TC-03: ROLE-BASED ACCESS CONTROL (RBAC) SEPARATION
    - Action: Log in with different staff roles:
      * Role 1: `TOURNAMENT_MANAGER` -> Can create/edit tournaments, CANNOT view user PAN/KYC docs or initiate ledger adjustments.
      * Role 2: `KYC_OFFICER` -> Can view/approve KYC documents, CANNOT alter financial balances or tournament stages.
      * Role 3: `FINANCIAL_AUDITOR` -> Read-only access to double-entry ledger and withdrawal queues.
    - Expected Result:
      * Unauthorized tabs/buttons are either hidden or strictly return 403 Forbidden on click.

[ ] TC-04: SESSION TIMEOUT & SECURE LOGOUT
    - Action: Click "Logout" in admin profile dropdown.
    - Expected Result:
      * JWT tokens are invalidated, session storage cleared.
      * Redirects immediately back to login screen.
      * Pressing browser "Back" button does NOT restore access to cached dashboard data.
