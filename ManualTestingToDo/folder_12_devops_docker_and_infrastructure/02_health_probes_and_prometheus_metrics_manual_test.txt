[ ] TC-02: DEEP READINESS PROBE (`GET /health/ready`)
    - Action: Send GET request to `http://localhost:3000/api/v1/health/ready`.
    - Expected Result:
      * Executes `SELECT 1` on PostgreSQL and `SET health_check` on Redis.

      * Load balancer immediately halts routing traffic to this container.
      * Restart Postgres (`docker start postgres`) -> Probes recover to HTTP 200 automatically.
