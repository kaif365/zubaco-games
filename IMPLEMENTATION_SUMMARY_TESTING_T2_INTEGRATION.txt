5. INTEGRATION TESTS ADDED  (19 total, all passing)
--------------------------------------------------------------------------------
Redis primitives (redis-primitives.integration.spec.ts) — 10:
  1. SETNX grants lock to exactly one acquirer, blocks the rest
  2. Lock re-acquired after DEL release
  3. Idempotency key: first write new, replays suppressed; window via EXPIRE
  4. INCR monotonic counter (rate-limit primitive)
  5. SET/GET value; SETEX TTL honoured (TTL > 0); DEL removes
  6. Sorted-set ranking highest-first (ZREVRANK, 0-based)
  7. Ordered top-N with scores (ZREVRANGE WITHSCORES)
  8. Single member score + score update on re-add (ZSCORE / ZADD)
  9. Score-range filter (ZRANGEBYSCORE) + member removal (ZREM)
 (grouped as 8 logical `it` blocks covering the above operations)

EventBus (event-bus.integration.spec.ts) — 5:
  1. Single publish fans out one outbox record per subscriber; dedupe marker set
  2. Duplicate publish of the same event id is suppressed (replay protection)
  3. drain() delivers the event to the subscriber and acknowledges (outbox emptied)
  4. Failed delivery is rescheduled (attempt=1, future next-attempt, no DLQ)
  5. Delivery dead-lettered once the attempt cap (8) is reached

Webhook (webhook.integration.spec.ts) — 5:
  1. Enqueued envelope carries a correct, receiver-verifiable HMAC-SHA256 signature
  2. Config gate: no destination URL => no enqueue (silent no-op)
  3. HTTP 200 delivery removes the record from the outbox
  4. Failed delivery reschedules with a recorded attempt + last_error (retry)
  5. Dead-lettered after max attempts (3) with the failing status recorded
